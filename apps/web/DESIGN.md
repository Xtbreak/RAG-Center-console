# 前端原型设计方向

## 定位

面向企业内部管理员、知识库管理人员和使用者的高密度 RAG 运维控制台。视觉重点不是营销，而是让文档处理、模型状态、自动选库和引用链路随时可追踪。

## 设计令牌

- 墨色 `#172033`：标题与高优先级正文。
- 岩灰 `#5C667A`：说明与次级信息。
- 雾白 `#F5F7FA`：全局背景。
- 纯白 `#FFFFFF`：工作区与浮层。
- 行动蓝 `#315EEA`：主操作、焦点和当前导航。
- 运行绿 `#16815D`：成功与健康状态。
- 告警红 `#C2414F`：失败与破坏性操作。

中文采用 `PingFang SC`、`Microsoft YaHei`、系统无衬线回退；数字采用 tabular figures。避免依赖外部字体服务。

## 布局

```text
┌──────────────┬──────────────────────────────────────────────┐
│ 产品与角色    │ 页面标题 / 全局搜索 / 通知 / 角色切换         │
│              ├──────────────────────────────────────────────┤
│ 主导航        │ 页面工具栏                                   │
│              ├───────────────────────┬──────────────────────┤
│ 系统状态      │ 主任务区               │ 引用 / 详情抽屉       │
└──────────────┴───────────────────────┴──────────────────────┘
```

- 桌面端使用 236px 固定左侧导航，内容左对齐。
- 平板与手机改为顶部栏和抽屉导航；表格转换为可换行记录卡。
- 使用边框、留白和局部底色编码层级，避免所有内容都变成同样的圆角卡片。
- 动效仅用于抽屉、弹窗、进度与状态反馈，并尊重 `prefers-reduced-motion`。

## 识别性元素

文档导入详情使用横向“处理轨道”展示上传、解析、图片理解、切分和向量化，让用户一眼识别当前所在阶段、耗时和失败恢复入口。

## 自检调整

- 放弃生成规范中的营销型 Hero，改为任务优先的后台工作区。
- 放弃 Outfit/Work Sans 作为中文主字体，改为无需联网的系统中文字体。
- 不使用装饰渐变和连续滚动揭示动画，避免干扰高频管理操作。
